## <a id="english"></a>🇬🇧 English

This repository contains structured SQL exercises, data manipulation practices, and relational database management scripts implemented in Microsoft SQL Server (SSMS) using T-SQL, focused on building robust backend data foundations.

### 📂 Repository Structure

- **`Basic-Commands/`**: Fundamental DML operations including database creation, table design with `IDENTITY` primary keys, `INSERT`, `UPDATE`, `DELETE`, and `TRUNCATE` operations, alongside conditional filtering (`WHERE`, `BETWEEN`, `LIKE`, `IN`, `AND`, `OR`), distinct records (`DISTINCT`), sorting (`ORDER BY`, `TOP / PERCENT`), and dynamic date calculations (`DATEDIFF`).

### 🛠 Tech Stack & Tools
- **Database Management System:** Microsoft SQL Server (MS SQL)
- **Environment:** SQL Server Management Studio (SSMS)
- **Query Language:** T-SQL (Transact-SQL)
- **Version Control:** Git, GitHub, GitHub Desktop

*Bridging database fundamentals with backend development to build scalable, data-driven systems.*

## <a id="türkçe"></a>🇹🇷 Türkçe

Bu repo, T-SQL kullanılarak Microsoft SQL Server (SSMS) üzerinde geliştirilmiş yapılandırılmış SQL egzersizleri, veri manipülasyon pratikleri ve ilişkisel veritabanı yönetim betikleri içermekte olup, sağlam backend veri temelleri oluşturmayı amaçlamaktadır.

### 📂 Depo Yapısı

- **`Basic-Commands/`**: Veritabanı oluşturma, `IDENTITY` birincil anahtarları ile tablo tasarımı, `INSERT`, `UPDATE`, `DELETE` ve `TRUNCATE` işlemlerini içeren temel DML operasyonları; koşullu filtreleme (`WHERE`, `BETWEEN`, `LIKE`, `IN`, `AND`, `OR`), tekilleştirme (`DISTINCT`), sıralama (`ORDER BY`, `TOP / PERCENT`) ve dinamik tarih hesaplamaları (`DATEDIFF`).

### 🛠 Teknoloji Yığını ve Araçlar
- **Veritabanı Yönetim Sistemi:** Microsoft SQL Server (MS SQL)
- **Ortam:** SQL Server Management Studio (SSMS)
- **Sorgu Dili:** T-SQL (Transact-SQL)
- **Versiyon Kontrolü:** Git, GitHub, GitHub Desktop
